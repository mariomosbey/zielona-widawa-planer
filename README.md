# Zielona Widawa – planer wnętrz 3D

Interaktywny planer wnętrz 3D (Three.js, jeden plik `index.html`) – układanie mebli i przebudowa (ściany, drzwi, okna, podłogi) w stylu Sims.

- **Udostępnianie:** przycisk „Udostępnij link” kopiuje adres z całym układem zapisanym w części `#...` – nic nie jest wysyłane na serwer.
- Źródła: `src/`, składanie: `python3 build.py` → `index.html`.
